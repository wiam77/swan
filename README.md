# swan
`swan` is a state management library for Luau focused on good developer experience.

# Installation
## Pesde
```console
# pesde add wiam/swan && pesde install
```

## Wally
Add the following to your `wally.toml`, in the `[dependencies]` section:
```toml
swan = "wiam77/swan@<version>"
```

Then run:
```console
# wally install
```
