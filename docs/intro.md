# Installation
## Pesde
```console
# pesde add wiam/swan && pesde install
```

## Wally
Add the following to your `wally.toml`, in the `[dependencies]` section:
```toml
swan = "wiam77/swan@<version>"
```

Then run:
```console
# wally install
```

## npm
`swan` provides typings for TypeScript.
```console
# npm install @rbxts/swan
```
